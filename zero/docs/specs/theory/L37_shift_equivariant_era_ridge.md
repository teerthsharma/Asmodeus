## 1. The group and its action

S0 (action). For s in R let T_s act on the stored coefficients a_{kx,ky} -> e^{-i kx s} a_{kx,ky} (physical: omega(x,y) -> omega(x-s,y)). On the real coordinates it is, per complex mode, the 2x2 rotation by -kx*s; it is an orthogonal matrix rho_x(s) on R^90, and well defined on the 80-dimensional subspace of Hermitian-consistent states because the ky = 0 partner at -kx rotates by +kx*s, the conjugate rotation. Let C: (Re, Im) -> (Re, -Im) on every stored coordinate. Then C T_s C = T_{-s}: the group is O(2) = {T_s} semidirect {1, C}. Orthogonal on R^90, so on stacked rows s_t = [x_t, x_{t-1}] and on targets y_t = x_{t+1} - x_t it acts blockwise by the same matrix (the lag copy and the increment are linear in x).

S1 (the PDE and the solver commute with T_s). PROVED.
(a) Continuous vorticity equation d_t w + u.grad w = nu lap w + f(y): u.grad w, lap and w -> -lap^-1 w commute with x-translation; f does not depend on x. So the vector field F satisfies F(T_s w) = T_s F(w) for every s and every law.
(b) The solver. `ns2d.simulate` evaluates the advection by FFT products and multiplies by the 2/3 mask (`maskh`, |kx|, |ky| <= n/3 = 10.67). Fields have |k| <= 10; a product has |k| <= 20; on the n = 32 grid the modes with |k| in {17..20} alias to |k| in {12..15}, and everything with |k| > 10 is zeroed by the mask, so after masking the discrete tendency equals the Galerkin convolution sum on the 21x11 half plane. That sum is a polynomial in the coefficients with each term's phases multiplying consistently (kx adds), so it commutes with the diagonal phase action T_s. The mask, nu*k2h*wh, and the forcing coefficients (nonzero only at kx = 0, where T_s acts as the identity) commute with T_s. RK4 is a composition of these maps and linear combinations, so one snapshot map Phi (10 RK4 steps) satisfies Phi(T_s w) = T_s Phi(w) exactly, in exact arithmetic (floating point breaks it only at rounding, ~1e-16).
(c) Law switches. `regime_schedule` draws start times and classes from a rng that does not read the state; the switch changes (nu, f) only. So at every step the law applied is state-independent, and each of the four laws is T_s-equivariant, hence so is the switched flow.
(d) Initial law. `simulate` draws Gaussian white noise, multiplies by exp(-k2/(2*9)) * mask, zeroes (0,0), divides by the field rms: a stationary isotropic Gaussian field up to a shift-invariant normalisation, so its law is T_s-invariant.
Consequence: (omega_t, law_t) has a T_s-invariant joint law for every t, and (x_t, x_{t-1}, x_{t+1}) is T_s-covariant.

S2 (conjugation = rotation by pi; the half-spectrum convention). PROVED.
The map R_pi: omega(r) -> omega(-r). Its Fourier action is a(k) -> a(-k) = conj(a(k)) for real fields. In the rfft2 half-plane convention the stored coordinate at (kx, ky) is a(kx, ky); R_pi sends it to a(-kx,-ky), which for ky > 0 lies outside the stored half plane and equals conj a(kx, ky); for ky = 0 it equals conj a(kx,0), also stored. So R_pi acts on the stored vector as C, coordinate by coordinate, with the same label. It is a symmetry because: u.grad w is invariant under (x,y) -> (-x,-y) (u -> -u and grad -> -grad, the product keeps its sign); lap is invariant; the forcing amp*cos(ky*y) is even in y (phase 0, kx = 0), so f(-x,-y) = f(x,y). Mask and truncation sets are symmetric under k -> -k. Not true in general: a law with phase != 0 gives f(-x,-y) = amp*cos(ky*y - phase) != f unless combined with a shift; for this bed all four phases are 0. The conj symmetry does NOT hold in the "a -> conj(a) as an antiunitary on psi" sense used by the encoder: the encoder's random frame R mixes coordinates, so C is orthogonal on x but not diagonal on phi; all symmetrisation must be done on x (recovered exactly by `_rows_from_phi`).

S3 (extra symmetry, bed-specific). y -> y + pi acts as (-1)^{ky}; all four forcings have ky in {2,4}, so cos(ky*(y+pi)) = cos(ky*y): an exact Z2 of every law in the bank. Not claimed by the coordinator; found by the same argument; it would shrink V_Q further (separate even-ky and odd-ky sectors). It is a property of the law bank (given information), so it enters only through the data-driven scan of section 7, never by hand.

## 2. Q1: the conditional mean and the population ridge optimum commute with the group

Statement. Let Gamma be the group of S0, rho_z, rho_y orthogonal representations of it on feature space and on target space with a shift-closed library, i.e. psi(g.s) = rho_z(g) psi(s) (true for: linear [x_t, x_{t-1}], the intercept, and the full quadratic library in the orthonormal basis of section 3; true for a reduced library iff its coordinate set J is a union of complete complex modes, because T_s mixes Re and Im of one mode and C flips Im). Assume the joint law of (s, y) is invariant: (g.s, rho_y(g) y) =_d (s, y). Then
(1) m(s) := E[y | s] satisfies m(g.s) = rho_y(g) m(s) almost surely;
(2) for every lambda >= 0 the population ridge optimum W*_lambda = argmin E||y - W^T psi(s)||^2 + lambda||W||^2 (minimum norm if lambda = 0 and the Gram is singular) lies in V_Q := {W : W^T rho_z(g) = rho_y(g) W^T for all g}.
Proof. (1) Show that s -> rho_y(g)^-1 m(g.s) is a version of E[y | s]. For bounded h: E[h(s) rho_y(g)^-1 m(g.s)] = rho_y(g)^-1 E[h(g^-1.s') m(s')] with s' = g.s, which has the same law as s, so this is rho_y(g)^-1 E[h(g^-1.s) m(s)] = rho_y(g)^-1 E[h(g^-1.s) y] (tower). Apply invariance (s, y) =_d (g.s, rho_y(g) y) to the function (s, y) -> h(g^-1.s) y: E[h(g^-1.s) y] = E[h(s) rho_y(g) y]. Hence the expression equals rho_y(g)^-1 rho_y(g) E[h(s) y] = E[h(s) y]. A version of the conditional expectation is unique a.s., so rho_y(g)^-1 m(g.s) = m(s), i.e. m(g.s) = rho_y(g) m(s). (2) Let H = E psi psi^T, G = E psi y^T. Invariance gives rho_z H rho_z^T = H and rho_z G rho_y^T = G for all g. W* = (H + lambda I)^-1 G; since rho_z is orthogonal, rho_z (H + lambda I)^-1 rho_z^T = (H + lambda I)^-1, so rho_z W* rho_y^T = W*, i.e. W*^T rho_z^T ... equivariance. For lambda = 0 the minimum-norm solution H^+ G is also invariant (the pseudo-inverse commutes with orthogonal conjugation). QED PROVED.
Needs: law invariance of (s, y), which holds here by S1(d) and S1(a-c); it does not need the sample to be invariant. The sample is not: one finite trajectory is not shift-invariant, which is why Q2 exists. Unobserved quantities (unresolved modes, the law class) are integrated out in m(s); invariance of their joint law with s is covered by S1 since the group acts on the full field.

## 3. Q2: augmentation by the 34 elements equals restriction to V_Q, exactly

Requirement R1 (invariant penalty). The ridge penalty must be invariant under the representations: rho_z orthogonal in the coordinates in which ||W||_F is penalised. Linear and intercept blocks: yes. The quadratic block in the monomial basis x_j x_k (j <= k) is NOT: Sym^2(rho) is orthogonal only for the Frobenius inner product on vec(x x^T), i.e. in the basis x_j^2 and sqrt(2) x_j x_k (j < k). So use that orthonormal basis (a fixed rescaling of 4095 columns by 1 or sqrt 2), with one invariant scalar weight per block (a constant between the linear and quadratic block, or a constant per isotypic frequency block; per-column standardisation as in stage C is not invariant and would break the equivalence). This is a correction to the way the claim was posed: with unnormalised monomials, augmented ridge != restricted ridge.
Statement. Let Gamma_17 = {T_{2 pi m/17} C^e : m = 0..16, e = 0,1} (order 34), a subgroup of O(2). Replace every row (z_t, y_t) by the 34 rows (rho_z(g) z_t, rho_y(g) y_t) and fit the ridge (same lambda, penalty on W unchanged, intercept unpenalised and fitted). Under R1, the minimiser equals the minimiser of the original sample ridge over V_Q (the O(2)-equivariant matrices).
Proof. Write J(W) = sum_t ||y_t - W^T z_t||^2 + lambda ||W||^2 and the action W^g with (W^g)^T = rho_y(g)^-1 W^T rho_z(g). The residual of the transformed row is rho_y(g) (y_t - (W^g)^T z_t), and ||W^g||_F = ||W||_F by orthogonality of both reps (R1). Hence J_aug(W) = (1/34) sum_g J(W^g) (up to a constant factor) =: <W, H_bar W> - 2<g_bar, W> + c, where H_bar, g_bar are the group-averages of the sample quantities. J_aug is strictly convex (lambda > 0), so it has a unique minimiser W_a. Applying W -> W^h permutes the terms of the average (Gamma_17 is a group), so J_aug(W^h) = J_aug(W); by uniqueness W_a^h = W_a for all h in Gamma_17, i.e. W_a is Gamma_17-equivariant.
Claim: Gamma_17-equivariant = O(2)-equivariant for these W. Decompose z and y into characters of T_s (complexify): a component of frequency f transforms by e^{i f s}. The linear and intercept features have |f| <= 4, the quadratic features |f| <= 8 (sum of two frequencies each in [-4,4]); the targets have |f| <= 4. An equivariant W only has entries between an input component of frequency f_in and an output component of frequency f_out with e^{i(f_in - f_out) 2 pi m/17} = 1 for all m, i.e. f_in - f_out = 0 mod 17. Since |f_in - f_out| <= 8 + 4 = 12 < 17, this forces f_in = f_out, which is the O(2)-condition on shifts; C-equivariance is imposed directly by the e = 1 elements. The group sum identity used: sum_{m=0}^{16} e^{2 pi i m f/17} = 0 for f not = 0 mod 17 (`IsPrimitiveRoot.geom_sum_eq_zero`).
Therefore W_a is in V_Q. For W in V_Q, W^g = W, so J_aug(W) = J(W). W_a minimises J_aug over all W, hence over V_Q, where J_aug = J: W_a minimises J over V_Q; uniqueness by strict convexity. QED PROVED.
Which bound is needed. The proof needs only |f_in - f_out| <= 12, so 13 shifts would do for the equality (13 x 2 = 26 elements). House's bound (every Gram entry is a degree-4 monomial with |sum kx| <= 16 < 17) is the condition for the other, stronger statement: H_bar, the average over the 17 shifts of the sample Gram, equals the average over the whole circle of the Gram (so the 17-fold data augmentation produces exactly the block-diagonal-by-frequency Gram, with no aliasing between frequency f and f +- 17). HAND-CHECKED on the actual lattice: Gram entries are of the form sum z z^T with z = [x_t, x_{t-1}, q(x_t), 1]: degree <= 4 in x (q q^T). Each x-coordinate is a real combination of a_{kx,ky} and conj a_{kx,ky}, frequency +-kx with |kx| <= 4; a product of four has frequency of absolute value <= 16; the cross-moment with y has degree <= 3 in x times one y coordinate (also |f| <= 4): |f| <= 16. So 16 < 17, and 17 is the smallest modulus for which the Gram-side statement holds (a degree-4 monomial with all kx = 4 has frequency 16). For the estimator the weaker bound suffices; I would use 17 shifts only if the code wants the block-diagonal Gram identity (it does, see Q5).
Computation without augmenting data: the average over Gamma_17 is a linear projection of the additive statistics; in the complex frequency basis rho(g) is diagonal (characters), and averaging zeroes every Gram entry whose two components differ in frequency. So H_bar is block diagonal by frequency, and one can accumulate only the diagonal blocks.

## 5. Q4: error ordering on every sample, bias of any energy-constrained estimate

Statement. Let V be a linear subspace (here V_Q), J(W) = <W,(H_hat + lambda)W> - 2<g_hat,W> + c the sample ridge objective (H_hat = G_hat (x) I, G_hat the sample Gram), W_u its unrestricted minimiser, W_Q its minimiser over V (= the augmented ridge by Q2). Then for every sample, every lambda > 0 and every w in V
 ||W_u - w||^2_{H_hat+lambda} = ||W_u - W_Q||^2_{H_hat+lambda} + ||W_Q - w||^2_{H_hat+lambda}.
In particular ||W_Q - w||_{H_hat+lambda} <= ||W_u - w||_{H_hat+lambda}, with equality iff W_u in V; and J(W_Q) - J(W_u) = ||W_u - W_Q||^2_{H_hat+lambda} (the exact sample-loss price of imposing the symmetry).
Proof. W_u solves (H_hat + lambda) W_u = g_hat. For v in V, optimality of W_Q gives <v, (H_hat + lambda) W_Q - g_hat> = 0, i.e. <v, (H_hat + lambda)(W_Q - W_u)> = 0: W_Q - W_u is (H_hat + lambda)-orthogonal to V, and W_Q - w is in V. Pythagoras in the inner product (H_hat + lambda) (`norm_add_sq_eq_norm_sq_add_norm_sq_of_inner_eq_zero` with `Matrix.InnerProductSpace.ofMatrix`). The loss identity: J(W) - J(W_u) = ||W - W_u||^2 for the quadratic J. QED PROVED.
Answers to the challenge.
- "Does Q4 need w* in V_Q under ridge (lambda > 0), or only in the population?" The inequality holds for ANY w in V, so it needs no statistical assumption at all. What needs the population assumption is that the natural target w* (the population ridge optimum W*_lambda) lies in V_Q, which is Q1 (law invariance, any lambda >= 0, because the penalty is invariant under orthogonal reps, R1). The ridge shift W*_lambda - W_0 (W_0 the lambda = 0 optimum) is itself in V_Q. So both targets are in V_Q; the comparison against either holds in the sample norm. Without R1 (non-invariant penalty) W*_lambda is not in V_Q and Q4 fails.
- Population-norm version: E||W_Q - w*||^2_{H+lambda} <= E||W_u - w*||^2_{H+lambda}. CONJECTURE, not proved: the sample-norm Pythagoras does not transfer, because W_Q is not the Euclidean projection of W_u onto V (H_hat does not commute with it). What is proved: if H_hat commuted with the projector P_V (e.g. the sample were exactly invariant) then W_Q = P_V W_u and the population-norm inequality holds pointwise. Expectation of the cross term is O(1/n) times the noise in V-perp; I do not claim it.
- Constrained to Wcons_M (any subspace V' not containing w*): for every sample and every estimate W in V', ||W - w*|| >= dist(w*, V') in any norm; the bias is dist(w*, Wcons_M) = ||Pi_perp w*_q|| (Pi_perp = the block-local projector onto the violation of the cubic form, `cameron.md` L31(i)), positive iff the cubic form c*(x) = <x, M Q*(x)> of the population quadratic part is not identically zero. PROVED (trivial). That the band leak makes c* nonzero is a CONJECTURE: the mean resolved enstrophy flux E[<x, M P B(w_full)>] = -(forward cascade rate) < 0 in the forced-dissipative steady state (forcing at ky = 2, 4 inside the band, nu small, enstrophy goes forward through the |k| = 4 edge), so the flux function F(x) = <x, M E[B | x]> is not zero, but F need not have a cubic component, and its mean can be absorbed by a linear (eddy) damping term, which the model is free to learn.
- A one-sided leak cannot be represented by a quadratic nonlinearity. PROVED: c(x) = <x, M Q(x)> is a cubic form, odd: c(-x) = -c(x). If c <= 0 everywhere then c(-x) = -c(x) >= 0, so c = 0. ## 7. L-GIVEN data-driven symmetry scan

What is given: only a finite menu of candidate symmetries (a hypothesis space): lattice directions kappa in {(1,0), (0,1), (1,1), (1,-1)} for continuous shifts T^kappa_s (a_k -> e^{-i <kappa,k> s} a_k), and the discrete candidates C, y-shift by pi, x-shift by pi. Which of them hold is selected from data.
Statistic (exact and free). For candidate subgroup Gamma_c with projector Sym_c on the additive state, compute the restricted ridge W_Q^c and the sample-loss price Delta_c := J(W_Q^c) - J(W_u) = ||W_u - W_Q^c||^2_{H_hat+lambda} (Q4). It uses only the additive statistics and costs one block solve. Large Delta_c means the sample is far from invariant.
Level (exact finite-sample, no bound constants needed). H0_c: the law of a trajectory is Gamma_c-invariant. Trajectories are independent (distinct seeds, `_gen` uses rng [seed, i]). Replace trajectory i by g_i . traj_i with g_i drawn independently and uniformly from a finite subgroup of Gamma_c; under H0_c the dataset's law is unchanged, so Delta_c computed on B randomised datasets and on the observed one are exchangeable: p_c = (1 + #{b : Delta^(b) >= Delta_obs})/(1 + B) satisfies P(p_c <= alpha) <= alpha under H0_c (Lehmann-Romano, randomisation tests). PROVED (standard). Select every candidate with p_c > alpha/|menu| (Bonferroni over the menu).
False-selection bound (a candidate that is not a symmetry accepted). Let u_i in a Hilbert space be the trajectory-i time-average of the discarded (non-invariant) degree <= 4 moment vector (the part of the Gram and cross-moment that Sym_c removes), clipped so that ||u_i|| <= R almost surely (winsorise the state at a radius B; enstrophy is bounded in the physical flow but I do not prove a bound; R <= B^4 for degree 4). c := E u_i is the violation; H0_c iff c = 0. Pinelis (1994, Thm 3.5; not re-proved here, not in Mathlib): for independent bounded vectors in a Hilbert space, P(||u_bar - c|| >= t) <= 2 exp(-n t^2 / (8 R^2)). Set tau = R sqrt(8 log(2/alpha)/n) and accept iff ||u_bar|| <= tau. Then (i) under H0_c, P(reject) <= alpha; (ii) if ||c|| >= 2 tau then P(accept) <= P(||u_bar - c|| >= ||c|| - tau >= tau) <= alpha. So every direction whose violation exceeds the minimum detectable effect 2 tau = 2R sqrt(8 log(2/alpha)/n) is falsely selected with probability at most alpha; with a union bound over the menu use alpha/|menu|. For n = 16 trajectories the effect size 2 tau is large (it scales as R/sqrt(n), n counts trajectories, not rows), so on the 16-trajectory sample the scan can only certify gross violations; a symmetry with small violation can be accepted. The bias from accepting a weakly violated symmetry is controlled by the computable price Delta_c (Q4), not by the bound. PROVED given Pinelis; the quantitative usefulness at n = 16 is CONJECTURE (R unknown).

## 8. Attacks, answered

A1 Conjugation under the half-spectrum convention: holds (S2): C = (Im -> -Im) on stored coordinates, ky = 0 included; fails for a law with a nonzero phase; acts orthogonally on x, not diagonally on phi (the encoder frame). OK given the phase-0 forcings in `LAWS`.
A2 Does E3 (the energy-shell rescale, `cameron.md` L31(iii)) commute with T_s? The factor is r = sqrt(||x_t||_M^2 + 2<x_t, A x_t + c>_M) / ||x_{t+1}||_M. M is T_s- and C-invariant (m depends on ky only). If A and c are in V_Q then <T x, A T x + c>_M = <T x, T(A x + c)>_M = <x, A x + c>_M, so r(T x_t, T x_{t+1}) = r(x_t, x_{t+1}) and the rescaled step is equivariant (C likewise). PROVED, conditional on A, c in V_Q (not true of an unrestricted fit, where the factor is a valid but non-equivariant map).
A3 Does Q4 need w* in V_Q under ridge? Answered in section 5: the inequality needs nothing; w*_lambda in V_Q needs law invariance and an invariant penalty (R1).
A4 Is "equals restricting the ridge exactly" true as stated? Only with R1 (orthonormal Sym^2 basis, invariant penalty); with the monomial basis or per-column standardisation the augmented and restricted ridge differ.
A5 Is the Z_17 bound the right one? Need |f_in - f_out| <= 12 for the equality; |sum kx| <= 16 < 17 for the Gram to equal the full-circle average (section 3).
A6 Does the symmetry survive switches, truncation, dealiasing, burn-in? Yes (S1), exactly in exact arithmetic; the law bank and IC share the symmetry.
A7 Does it survive the era machinery? Per-era statistics are sums over windows assigned by law residuals R, L: `NS2DLaw` reads (w1 - w0)/dt + adv and lap from the coordinates; T-covariant, so T-images of a window go to the same era (as the residual of R = nu L + f is shifted consistently, f only at kx = 0). Window membership is therefore a T-invariant function, which is what lets augmentation be done per era. CONJECTURE for the `_best_law` tie-breaks at the threshold _TAU (they are invariant functions of the residual norms, so invariant; I have not traced every branch).
A8 TT: not equivariant by construction (quantile bins of coordinates); the symmetry restriction does not apply to it; it answers only ALONE/OOD rows.
