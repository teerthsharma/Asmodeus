## 2025-05-18 - Jaccard Set Operations Bottleneck in Swarm Routing
**Learning:** In routing algorithms evaluated repeatedly across candidate models, computing set union via `set(a).union(b)` constructs a new Python set object on every call (O(|A|+|B|)), creating significant object allocation overhead and GC pressure. Since Jaccard similarity is `|A ∩ B| / |A ∪ B|`, and `|A ∪ B| = |A| + |B| - |A ∩ B|`, calculating `union_len` arithmetically using pre-converted sets eliminates set allocation entirely during similarity scoring. Additionally, when `k` is small relative to the number of candidate models `N`, `heapq.nlargest(k, ...)` avoids full list sorting overhead (O(N log k) vs O(N log N)).
**Action:** When computing set overlap/similarity metrics in critical loops, pre-convert sets outside the loop, use arithmetic identities to compute set sizes without allocating union sets, and use `heapq.nlargest` for top-k selection.
